The tool-selection map, the five cheap moves, and blank templates for your own five client stories — Trigger, Automate, Extend, Connect, Intelligise.

By Brynjar Jóhannesson at Wise, for Nordic Summit 2026 in Billund. Built to go with the "From Zero to Hero: 5 Steps to Automation in Business Central" session.

The Map

Two references, used in sequence. The data gate says what the data may touch; the map says which tool gets you there.

The Data Gate

TierWhat it isRuleReach
OperationalTransactional, internal, reversibleAutomate end to endSteps 1–5
SupervisedClient-facing, approval-sensitiveAI reads and suggests, a named human approvesSteps 1–5, human gate
RestrictedPrivileged, confidential, regulatedNo AI access, often no automationSteps 1–3 at most

Supervised data means a human approves; full autonomy means none. That caps you by arithmetic, not by timidity.

The Tool Map

What you needReach forDo not, when
React to something inside BC, no codeWorkflow EngineThe condition is not in the published event
Send it somewhere outside BCPower Automate + BC connectorHigh volume, or duplicates would hurt
React to something on your own objectsAL workflow eventYou are rebuilding standard
Real time, you own both endsHttpClient / API pageIt must not be lost — queue it instead
It must not be lost, or must survive an outageService Bus / queueA connector retry is genuinely enough
Judgement you cannot write downAI Builder / CopilotThe rule is knowable, or the data is restricted
A capable BC user could do it through pages and actionsBC native agentThe work is analytical or spans systems

Five Cheap Moves

One pitfall and one mitigation per step. None of these cost a sprint — they cost an hour, before you start.

1

Trigger

BC Workflow Engine

MOVERead the workflow event list before scoping.
2

Automate

Power Automate + BC connector
PITFALLIt ran twice. Now there are two postings.
MOVEOne page: every flow, its owner, where failures land.

Extend

AL workflow events
PITFALLYou're rebuilding standard before you publish the event.
MOVESearch the base app for the event first.

Intelligise

BC Workflow Engine

2 · Automate

Power Automate + BC connector

Session example: Kvartal Eiendom, property group, multiple entities — a flow fired twice and posted the same transaction twice.

AL workflow events

HttpClient / API pages

AI Builder + Copilot

The Horizon
